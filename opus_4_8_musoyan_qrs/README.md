# opus_4_8_musoyan_qrs

Adds navigation and video links to the scanned PDFs of Musoyan's two-volume
Mathematical Analysis textbook:

- nested bookmarks (chapters / sections / subsections) from hand-curated JSON,
- a clickable YouTube card on each chapter's opening page, pointing at the moment
  in the [Համալսարանական մաթեմատիկա](https://www.youtube.com/channel/UCMFONp28jEDHXDBWJyRVYcA)
  lecture where that chapter's material starts (both lecturers where both teach it),
- a thin clickable line at the foot of every page where a matched section or
  subsection begins (275 lines on 209 pages, timestamped, both lecturers;
  same-target lines on one page are deduplicated, and on a chapter's opening
  page a line appears only when it targets something the chapter card does not),
- a reader-info page before chapter 1 (searchability, bookmarks, extra materials link).

The deliverables are `out_pdf/musoyan_1_final.pdf` and `out_pdf/musoyan_2_final.pdf`.

## Pipeline

```
musoyan_{1,2}.pdf            fixed_bookmarks_{1,2}.json      .env (YOUTUBE_DATA_API_KEY)
      |                             |                               |
      |                             |                        fetch_videos.py        (YouTube Data API, ~40 quota units)
      |                             |                               |
      |                             |                        videos/all_videos.json, channel.json, playlists/
      |                             |                               |
      |                             +------ reconcile_videos.py ----+   (+ manual_matches.json, hand-curated)
      |                             |              |
      |                             |       videos/matches.json, analysis_index.json
      |                             |              |
      |                             |       build_match_report.py -> videos/match_report.html  (review UI)
      |                             |              |
      |                             |       make_video_links.py -> video_links.json  (chapter cards + section lines)
      |                             |              |
      +---------- build.py <-------+--------------+
                      |
      out_pdf/musoyan_{1,2}_final.pdf   (bookmarks + info page + link cards, verified)
```

## Rebuild from scratch

```
python fetch_videos.py        # only if the channel changed; needs .env, ~1 min
python reconcile_videos.py    # deterministic matching, no API, seconds
python make_video_links.py    # matches.json -> video_links.json (chapter links)
python build.py --style card  # the deliverable; ~25 s for both volumes
```

`build_match_report.py` regenerates the human review page from `matches.json` at any
time. `apply_bookmarks.py` + `place_video_links.py` are the preview path: bookmarks
only, then per-style link previews on top (icon / chip / card / footnote);
`design_gallery.py` renders all badge designs on one PDF for comparison.

## Data files and numbering

- `fixed_bookmarks_{1,2}.json` - the bookmark tree. Pages are 1-based pages of the
  SOURCE PDFs (vol 1 = printed page + 1, vol 2 = printed page + 0).
- `video_links.json` - GENERATED by `make_video_links.py`; edit the pipeline, not
  the file. Same source numbering; `build.py` shifts everything past the inserted
  info page by one at build time.
- `manual_matches.json` - hand-verified match overrides / approvals / rejections,
  keyed by exact heading title (typos fail loudly). The one file worth backing up.
- `videos/` - fetched channel data and derived matches; fully regenerable.

## Notes

- Windows-only as written: label fonts come from `C:/Windows/Fonts/` (Segoe UI has
  Armenian glyph coverage; base-14 Helvetica silently cannot - see `_learnings/`
  at the repo root).
- Needs `pymupdf` (+ `fonttools` for font subsetting), `requests`, `python-dotenv`.
- `musoyan_1.pdf` has a pre-existing dangling xref; MuPDF prints
  `cannot find object in xref (3837 0 R)` on every full save and repairs it. Benign.
- Design choices and their reasons live in `DECISIONS.md`. Session history is in
  `_work_sessions/` at the repo root.
